# aruodore.com

The public practice of a mathematician and statistician building systems that reason under uncertainty: interactive, browser-native pieces at the intersection of probability theory, statistical inference, computer vision, and machine learning.

```sh
npm install
npm run dev
```

`CLAUDE.md` is the source of truth for this repo's design system, content schemas, and conventions.
